# Тестирование REST и SOAP API через Postman

[Коллекция в Postman]([https://www.postman.com/volozhanin-iteam/workspace/qa/collection/34240462-d37b40c3-1033-45b9-b75e-45ab9ee3e6c6?action=share&creator=24148348](https://github.com/Ramilia7/api/blob/main/DemoShopping.postman_collection.json) протестированы все методы, предоставленные в Swagger https://qa.demoshopping.ru/api-docs/, и создана соответствующая коллекция с автотестами

[Генерация тестовых данных](https://github.com/Ramilia7/api/blob/main/Random.postman_collection.json) генерация тестовых данных с рандомными  значениями, соответствующими типу данных для каждого ключа

[Тестирование SOAP методов](https://github.com/Ramilia7/api/blob/main/Soap.postman_collection.json) создана коллекция в Postman для тестирования сервиса http://webservices.oorsprong.org/websamples.countryinfo/CountryInfoService.wso?WSDL, который предоставляет информацию о целевой стране
